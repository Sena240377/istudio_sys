# 改善効果を測る指標

目的は「適切な学習支援を受けられる割合を高め、気軽に利用できる状態を保つ」こと。ミスマッチだけを課題と断定しない。目標値・導入前値は管理者が入力するまで未取得。架空の改善率や導入前値を補完しない。集計期間と DEMO / REAL を画面に表示する。

| 指標               | 分子・分母 / 単位                                               | 記録源・解釈                                                                                                                                                               |
| ------------------ | --------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 学生満足度         | 回答の満足度合計 / 回答数、1～5                                 | 任意アンケート。未回答者の満足度は不明                                                                                                                                     |
| ミスマッチ発生率   | 「対応できていなかった」回答数 / 対応可否回答数、%              | 学生回答に基づく。専門科目の不一致そのものをミスマッチとしない                                                                                                             |
| 予約受付成立率     | 成功した予約試行数 / 全予約試行数、%                            | BookingAttempt の試行日時で集計。関連分野の「受付成功・対応確認待ち」を含むため、確認待ち件数を併記する。認証・CSRF エラーや単なる検索・離脱は数えない。飛び込みは含めない |
| 利用者数           | 来室記録のある内部学生 ID の重複を除いた数、人                  | チェックイン済み・指導中・完了。予約だけでは利用と数えない                                                                                                                 |
| キャンセル率       | キャンセル予約数 / 対象予約数、%                                | 予約日コホート。飛び込みと予約を区別し、観察期間が短い予約では結論を急がない                                                                                               |
| 事前準備率         | 準備済みの完了指導数 / 準備状態を入力した完了指導数、%          | 未記録を準備不足と断定しない。準備状況記録数 / 完了指導数も点検                                                                                                            |
| 指導時間の有効活用 | 完了指導の有効指導分数合計 / カルテ記録がある完了指導数、平均分 | TA の自己記録、0～35 分。学習成果との関係は別に調査する                                                                                                                    |
| 解決率             | 解決した回答数 / 解決可否回答数、%                              | 学生アンケート。任意回答のため回答偏りがある                                                                                                                               |
| カルテ記録率       | カルテがある完了指導数 / 完了指導数、%                          | 保存の有無。記述の質まで保証しない                                                                                                                                         |
| 無断欠席率         | 無断欠席予約数 / 対象予約数、%                                  | 受付による確認。未チェックインだけで自動判定しない                                                                                                                         |

日・曜日・時間帯・月別は、チェックイン日時のある予約から、各区間の内部学生 ID を重複除外して人数を集計する。来室後にキャンセルした場合も、来室の事実は件数・人数に残る。曜日別は期間内でその曜日を利用した人数であり、曜日ごとの平均人数ではない。科目別は期間内の相談予約件数で、来室数・予約成立率とは分けて読む。新規・リピートは、保存済み履歴内でその学生の最初の来室を判定する。旧システム履歴を取り込んでいないため、生涯での初回利用と断定しない。TA 別稼働はキャンセルを除いた相談予約件数の運用集計であり、能力・満足度のランキングではない。

予約総数・来室・品質指標は予約の開始日時、予約受付成立率は操作の試行日時で集計する。指導完了済みの予約コホートに紐づくアンケートを品質指標に用いる。遅れて回答した場合は過去期間の指標が更新される。回答率も併記する。

導入前後の比較では、同じ期間長・曜日構成・学期時期・集計定義・回答対象をそろえる。比較対象は満足度、ミスマッチ、予約受付成立、キャンセル、利用者数、解決率。導入前データがなければ未取得と表示し、改善を断定しない。手入力した導入前値は根拠資料と期間を運用記録に残す。自動的な因果推論・統計的有意差判定は実装範囲外。

現場確認が必要な点: 現行予約の分母、予約の成立時点、通常の準備時間、キャンセル期限、無断欠席判定時刻、同一学生の複数回利用、既存データの欠測、学期による利用の偏り。これらは「要ヒアリング」であり、確定仕様として扱わない。
